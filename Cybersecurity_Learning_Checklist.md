
# 🛡️ Cybersecurity Learning Roadmap – Editable Checklist

## 🔹 Phase 1: Foundation (In Progress)
- [x] Google Cybersecurity Certificate
- [x] ISC2 Certified in Cybersecurity (CC)
- [ ] Basic Linux/Command Line (focus on logs, file system navigation)
- [ ] Networking Basics (TCP/IP, ports, protocols, OSI model)
- [ ] Security Principles (CIA triad, defense-in-depth, least privilege)
- [ ] Intro to Windows & Linux logs (Event Viewer, syslog, auth logs)

## 🔹 Phase 2: Log Analysis + SIEM
- [ ] Learn Splunk or Elastic Stack (Kibana, Logstash, Elasticsearch)
- [ ] Build log correlation queries (detect brute force, lateral movement, data exfil)
- [ ] Practice using MITRE ATT&CK to classify activity
- [ ] Get familiar with Sysmon (for enhanced Windows logging)

## 🔹 Phase 3: Digital Forensics
- [ ] Disk Forensics (file carving, deleted file recovery, metadata analysis)
- [ ] Memory Forensics (Volatility, malware injection detection)
- [ ] Timeline creation (log2timeline, Plaso)
- [ ] Artifact analysis: Registry, browser history, prefetch, jump lists

## 🔹 Phase 4: Incident Response Playbooks
- [ ] Understand IR lifecycle: Preparation → Detection → Containment → Eradication → Recovery → Lessons Learned
- [ ] Create response playbooks (e.g., for ransomware, phishing, lateral movement)
- [ ] Learn basic scripting (Python/Bash) to automate repetitive IR tasks
- [ ] Practice working with EDR tools like CrowdStrike or Velociraptor (community edition)

## 🔹 Phase 5: Intro to Malware Analysis (Stretch Goal)
- [ ] Static Analysis (strings, file signatures, PE headers)
- [ ] Dynamic Analysis (sandboxing, monitoring behavior)
- [ ] Basic reverse engineering (Ghidra, x64dbg)
- [ ] Understand malware persistence techniques and indicators

## 🎯 Bonus: Build Your Portfolio
- [ ] Document 2–3 forensic investigations (screenshots, timelines, findings)
- [ ] Build a mini lab with VirtualBox to simulate attacks and incident response
- [ ] Share insights or walkthroughs on GitHub or LinkedIn
- [ ] Solve weekly challenges at CyberDefenders.org
